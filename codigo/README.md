# codigo

Python validators using only the standard library.

- `validar_contexto.py`: checks the brand-context file has all 11 mandatory fields.
- `validar_pieza.py`: checks a piece against the rules (hook, CTA, claims, framework, sensitive topics).
- `verificar_reglas.py`: checks the rule documents do not contradict each other.
- `derivar_indice.py`: regenerates the content-bank index.
- `generar_fixtures_invalidos.py`: builds invalid fixtures for testing.
- `monoga_core.py`: shared utilities (text normalization, frontmatter, tables, console output).
- Subfolder: [tests/](tests/README.md).
