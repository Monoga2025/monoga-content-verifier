# banco

The content bank: the place where approved content pieces are stored and indexed.

- `INDICE.md` is generated by `codigo/derivar_indice.py` from the pieces themselves; do not edit it by hand.
- `piezas/` holds the individual piece files; it is empty in this copy.
- Piece state (approved, published, discarded) is changed by a human, never by the tool.
